# 我现在是怎么使用 Claude 的

经过前面的几次折腾，我现在打开 Claude 之前，一般会先做两个简单的检查，然后再登录。

## 第一步：检查网络有没有泄露

我会先打开之前用过的 [Claude 网络环境检测页面](https://ip.net.coffee/claude/)，看看 **DNS 和 WebRTC 有没有泄露**，检测到的网络信息是否符合自己的预期。

## 第二步：检查邮箱有没有收到 suspend 邮件

然后打开邮箱，看看有没有收到包含 **suspend** 的邮件。如果收到了，就先看看邮件具体说了什么，再决定下一步怎么处理。

## 第三步：打开 Claude 桌面端，开蹬

前面两项检查完，就打开 Claude 桌面端，登录自己的账号，然后直接开蹬。

这就是我现在的流程：**先检查网络，再看看邮箱有没有收到 suspend 邮件，最后打开 Claude 桌面端，登录开蹬。** 不同人的网络和账号情况不一样，这些检查也不能保证账号一定不会出现问题；遇到异常时，再根据具体提示排查。
