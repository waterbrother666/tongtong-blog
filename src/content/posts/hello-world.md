## 为什么要搭博客

把做过的事情写下来,既是整理,也是给未来的自己留线索。

## 这个博客用了什么

- **Astro**:内容优先,默认几乎不发 JS
- **Tailwind CSS**:样式
- **Markdown / MDX**:写文章
- **Giscus**:基于 GitHub Discussions 的评论
