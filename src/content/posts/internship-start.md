![从公司大堂往外看](/posts/internship-start/view.jpg)

## 上午

早上 9:15 就到公司了。刚到也没啥事,我就随便搞了一下自己的 UI 设计 Skill。

然后 11 点就被拉去开会了,一直开到 12:10 左右。主要就是给我介绍公司现在搞了些什么,还有现在的痛点是什么。

说是公司现在是基于 AccioWork 做的二次开发。具体就是在 AccioWork 上创建多个智能体,去综合管理我们的 AccioWork,也就是填几个 md 文件,再导入几个 skill。

## 他们的两个痛点

主要就两个:

- 用户在 AccioWork 上的安装太繁琐了,经常安装跟不上。他们想让我帮忙把整个安装流程简化掉。
- 现在整个流程其实还不够完善,方案要不断地改。

开完会就去吃饭了。

## 下午

吃完饭回来眯了一会儿,然后下午就一直在试这个简化的方案。一共弄了三个:

1. **智能体直接导出**:失败了,版本不兼容。
2. **插件的方式导入 zip**:把原来的智能体简化成了 skill + subagent 的格式。
3. **直接给千问办公 + Computer Use 提示词**,让它自己去实现对应的内容。

![下午的工位:左边 Mac,右边 Windows 笔电](/posts/internship-start/desk.jpg)

## 一个小失误

我忘了找老板要阿里巴巴账号,所以 zip 那个方案到底好不好用,今天还没法测。这个我印象还挺深的,以后做事之前得先把要用的账号问清楚。

## 明天

明天先跟他们说一下我的方案,然后顺便把账号要到,去测一下 zip 的效果。
