今天是实习的第一天,趁着记忆还新,把这一天记下来。

![从公司大堂往外看](/posts/internship-start/view.jpg)

## 上午:到公司,然后开会

早上 9:15 到的公司。没人给我安排活,我就先把自己的 UI 设计 Skill 随手调了调。

11 点,我被拉去开会,一直开到 12:10 左右。会上主要是向我介绍两件事:公司现在在做什么,以及现在的痛点是什么。

公司目前是**基于 AccioWork 做二次开发**。做法是在 AccioWork 上创建多个智能体,让它们去综合管理整个 AccioWork:往里面填几个 md 文件,再导入几个 Skill。

## 他们遇到的两个痛点

1. **用户在 AccioWork 上的安装很繁琐**,经常跟不上、装不起来。他们希望我帮忙把整个安装流程简化。
2. **整个流程本身还不够完善**,方案需要不断调整。

## 下午:试了三个方案

吃完饭回来眯了一会儿,下午一直在试"简化安装"的方案。我一共试了三种思路:

1. **智能体直接导出。** 失败了,原因是版本不兼容。
2. **用插件的方式导入(zip)。** 把原来的智能体简化成 **Skill + Subagent** 的格式,再打成 zip 导入。
3. **直接把提示词交给千问办公,加上 Computer Use**,让它自己去完成对应的安装和配置。

![下午的工位:左边 Mac,右边 Windows 笔电](/posts/internship-start/desk.jpg)

## 一个小遗憾

我忘了向老板要**阿里巴巴账号**,所以方案二的 zip 导入效果,今天还没法真正测。这一点我印象很深:动手之前先把测试需要的账号和权限问清楚,不然做完了也验证不了。

## 明天

- 向他们讲一下我的方案;
- 顺便把账号要到,把 zip 的效果测一遍。

实习的第一天,大概就是这样:开会、听痛点、试方案、发现自己漏了一件小事。明天继续。
