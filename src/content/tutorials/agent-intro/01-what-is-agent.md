## Agent 和聊天机器人的区别

普通的聊天机器人是"你问一句,它答一句"。Agent 则多了一件事:它可以**自己决定下一步做什么**,比如先去查资料、再调用一个工具、最后才给你答案。

## 一个 Agent 的三个部件

1. **模型**:负责理解任务、决定下一步。
2. **工具**:模型能调用的函数,比如搜索、读文件、查数据库。
3. **循环**:把工具的结果交还给模型,直到模型认为任务完成。
