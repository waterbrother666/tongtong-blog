## 先想清楚:你要它做什么

同样是"用 Claude",不同的任务适合不同的入口。先看任务,再选工具,比先学工具省事。

## 三种常见入口

### 1. 网页版和桌面应用:对话

最直接的方式:打开聊天界面,把问题或材料发给它。适合:

- 问问题、查思路、做总结;
- 润色和改写文字;
- 分析你贴进去的文档、截图或表格。

特点是**不需要写代码,也不碰你电脑上的文件**,门槛最低。

### 2. Claude Code:在你的项目里干活

Claude Code 运行在你的终端或桌面应用里,可以读你项目里的文件、改代码、运行命令。适合:

- 写功能、修 bug、重构;
- 搭一个新项目;
- 整理一个陌生的代码库。

它和聊天最大的区别是:**它能直接动你的文件**,所以需要理解"权限"(第 3 章会讲)。

### 3. API:把它接进你自己的程序

通过 API,你的程序可以调用 Claude 来完成任务,比如做客服、做审核、做内容生成。适合:

- 你要做一个产品,而不只是自己用;
- 需要把模型接到自己的业务流程里。

这需要写代码,也需要管理密钥和费用。

## 怎么选

| 你想做的事 | 用什么 |
| --- | --- |
| 问问题、写作、总结 | 网页版 / 桌面应用 |
| 改自己项目的代码 | Claude Code |
| 做一个给别人用的产品 | API |

大多数人从第一种开始,需要的时候再往后走。
